# Browser dataset — Project by Rohan Sai

browser_dataset.csv.gz contains 29,000 existing records sampled with seed 42 within the original periods: 20,000 fit (2014–2022), 4,000 validation (2023), 5,000 test (2024). The original and subset SHA-256 values are recorded in ../site-data.json. This is a demonstration subset, not new observations or synthetic labels.
